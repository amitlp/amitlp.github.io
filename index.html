Bank Statement OCR
github.com/vidyalai-in/bank-ocr
A fully local pipeline that converts bank statements (PDF or image, multi-page, any bank) into validated, structured JSON — no statement data ever leaves the machine. Ten pluggable parsers sit behind a single protocol in three families: native-text CPU parsers (pdfplumber, Camelot lattice/stream, PyMuPDF, PyMuPDF-layout, Tika) that need no GPU and no model download and finish in under 2 seconds per file — Camelot reaches 0.996 F1 on fully ruled grids and Tika leads every borderless layout measured; Docling, the default, which adds RapidOCR/PaddleOCR to read scans; and opt-in GPU models (MinerU, Marker/Surya, and GLM-OCR, a small MIT-licensed VLM with the highest recall at 99.5%). A per-parser Markdown dialect layer normalises their output so deterministic extraction of transactions and account fields holds across all of them. A local LLM (Qwen3-4B via Ollama) fills in the account holder name and acts as a fallback for non-tabular statements, and can be disabled entirely for fully deterministic runs. Running-balance math is self-validated, with discrepancies flagged rather than silently corrected. Designed to run comfortably under 8 GB of VRAM by keeping the parsing and LLM stages sequential.
Python OCR 10 Pluggable Parsers Local LLM Privacy-First
